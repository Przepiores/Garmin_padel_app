# Testy na sprzęcie

Kolejka zmian zrobionych w sesjach zdalnych (Claude Code na telefonie), które
trzeba sprawdzić na laptopie w symulatorze Connect IQ albo na zegarku.
Wpisy dodaje Claude (pilnuje tego hook `Stop` w `.claude/`), a przy starcie
Claude Code na laptopie hook `SessionStart` przypomina o otwartych pozycjach.

Po teście zmień `[ ]` na `[x]` i dopisz wynik.

## Format wpisu

```
- [ ] RRRR-MM-DD · `gałąź` · krótki opis zmiany
  - Gdzie: symulator / zegarek / kort
  - Sprawdź: konkretne kroki i oczekiwany wynik
  - Wynik: (uzupełnij po teście)
```
